CONTACT / CORRECTIONS

联系方式与纠错反馈

发现价格、线路、评分或链接有误？发现推广披露不清？欢迎反馈，我们会核对后更正并在更新记录中说明。

联系方式

Telegram：@outsideweb ↗

也可以通过 GitHub 仓库 Issues 提交反馈。Issue 内容会公开显示，请勿包含个人联系方式、账号凭证或其他敏感信息。

反馈前请准备

为了让资料能被准确修正，建议在消息中包含：机场名称、你在哪里看到的（本页 / 服务商官网 / 其他来源）、正确信息是什么，以及可核对的链接或截图。缺少来源的说法我们无法核实，也不会写进目录。

受理范围

  • 数据纠错：起步价、线路描述、参考分、官网链接错误或服务已停止。
  • 推广披露问题：外链推广参数未被清楚标注，或影响排序公正性的疑虑。
  • 版权与侵权：内容被不当引用、品牌名称使用争议。
  • 内容建议：希望补充的线路、预算场景或客户端问题。

本站不受理：代注册、代下单、代付、账号找回，以及任何要求解锁流量或协助绕过限制的请求。

处理时效

我们通常会在核对后的下一次内容更新中处理已证实的更正，并在 关于本站的更新记录中标注变更日期。不影响事实准确性的建议可能排期较晚。

合作说明

本站不接受付费改排名、付费撤榜单或付费提升参考分。任何形式的商业合作都不会改变目录顺序与参考分口径；合作内容会明确标注且不影响其他条目的呈现。

隐私说明

GitHub Issues 内容会公开显示；通过 Telegram 联系时也请勿发送订阅链接、账号凭证、付款信息或验证码。反馈截图和日志前请先遮挡敏感内容。
